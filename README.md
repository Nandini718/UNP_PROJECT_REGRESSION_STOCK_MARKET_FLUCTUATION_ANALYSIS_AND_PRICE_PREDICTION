# UNP_PROJECT_REGRESSION_STOCK_MARKET_FLUCTUATION_ANALYSIS_AND_PRICE_PREDICTION

I did this project in collaboration with UNP, where I created a Stock Market Fluctuation Analysis and Price Prediction project using Python and Regression Machine Learning.
The project analyzes historical stock-market data to understand price movements and estimate the Closing Price.
I performed data preprocessing, missing-value treatment, duplicate removal, and outlier detection.
Exploratory Data Analysis and correlation analysis were used to identify trends and relationships between variables.
Feature selection and VIF analysis were performed to select suitable independent variables.
The final features included Open, Volume, Daily Return, and Price Change.
I implemented Linear Regression, Decision Tree Regression, and Random Forest Regression models.
The models were tested using different train-test split ratios.
Performance was evaluated using MSE, MAE, RMSE, MAPE, and R².
Overall, the project demonstrates how regression techniques can analyze stock trends and estimate Closing Prices.
